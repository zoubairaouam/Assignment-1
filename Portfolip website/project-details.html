Project Details

More context about the projects, the decisions made and the skills developed.

Responsive website

Purpose

To build a website that presents information clearly across devices and demonstrates foundational web development skills.

Approach

HTML provides semantic structure, CSS controls layout and presentation, and JavaScript supports selected interactions. Accessibility is considered in navigation, text, focus states and form controls.

Further development

Continue reviewing contrast, content structure, responsiveness and the usability of interactive elements.

Python programming

Purpose

Develop programming fluency, use appropriate data structures and practice decomposing problems into manageable steps.

Approach

Write and test code incrementally, review outputs and refine the solution based on the results.

Further development

Improve documentation, test edge cases and consider efficiency and maintainability.

Database project

Purpose

Explore structured data, relationships and how queries can retrieve information from a database.

Approach

Develop database structure and practice SQL queries against a suitable dataset.

Further development

Consider validation, integrity constraints, query optimisation and user needs.
